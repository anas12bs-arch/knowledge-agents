# [finextra] Blik records first agentic payment transaction

> Source: finance | Category: finance | 2026-09-11T00:47:26Z

Blik records first agentic payment transaction

Polish mobile payment network Blik has run its first agentic payment transaction, under which a user authorised an agent to search for a specific product and pay for it when it became available.
