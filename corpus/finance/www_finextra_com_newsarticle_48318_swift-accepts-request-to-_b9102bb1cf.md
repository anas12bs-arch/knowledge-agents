# [finextra] Swift accepts request to extend structured address migration for ISO 20022 messages

> Source: finance | Category: finance | 2026-08-28T00:53:08Z

Swift accepts request to extend structured address migration for ISO 20022 messages

Swift is extending the November deadline for moving from unstructured to structured postal addresses for ISO 20022 payment messages after a host of banks asked for more time to comply.
