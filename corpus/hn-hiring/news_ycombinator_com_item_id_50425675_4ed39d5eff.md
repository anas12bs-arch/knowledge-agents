# HN Hiring (Ask HN: Who is hiring? (November 2026))

> Source: hn-hiring | Category: job-skills | 2026-11-09T19:46:39Z

DevOps Engineer
Hybrid, 3 days a week in the office
Hong Kong
Full-time<p>We are looking for a DevOps Engineer to own, scale, and secure our cloud and on-premise computing environments. You will work closely with ML researchers, data scientists, and software engineers to streamline model training, optimize GPU cluster utilization, and automate our continuous integration and deployment (CI&#x2F;CD) pipelines.<p>Core Responsibilities
AI &amp; GPU Infrastructure Management: Provision, monitor, and scale high-performance GPU clusters (NVIDIA H100&#x2F;A100, CUDA&#x2F;ROCm setups) for heavy model training and inference workloads.
MLOps &amp; Model Serving Pipelines: Support model deployment, fine-tuning, and low-latency inference optimization using open LLM ecosystems (e.g., vLLM, Triton Inference Server, Llama, Mistral).
CI&#x2F;CD &amp; Automation: Design, build, and maintain robust CI&#x2F;CD pipelines for both software services and ML model artifacts using GitHub Actions, GitLab CI, or ArgoCD.
Infrastructure as Code (IaC): Manage cloud resources (AWS, GCP, or Azure) repeatably using tools like Terraform or Pulumi.
Containerization &amp; Orchestration: Deploy, scale, and manage distributed containerized workloads using Kubernetes (K8s), Docker, and KubeFlow or Ray.
Observability &amp; Reliability: Implement logging, tracing, and metric dashboards (Prometheus, Grafana, OpenTelemetry) to track cluster health, GPU memory&#x2F;utilization, and inference latency.
Security &amp; Governance: Enforce DevSecOps practices, secret management (HashiCorp Vault), container image scanning, and access controls tailored for sensitive AI datasets and models.
Required Qualifications
Experience: 3+ years of experience in DevOps, Site Reliability Engineering (SRE), or Cloud&#x2F;Platform Engineering, with exposure to MLOps or AI&#x2F;ML workloads.
Cloud &amp; Containers: Strong hands-on experience with AWS, GCP, or Azure, alongside production Kubernetes and Docker management.
Scripting &amp; Programming: Proficiency in Python, Bash&#x2F;Shell, or Go for automation and tooling.
IaC &amp; CI&#x2F;CD: Demonstrated mastery of Terraform, GitOps workflows, and automated testing&#x2F;deployment pipelines.
AI Ecosystem Knowledge: Familiarity with GPU node provisioning, distributed storage for massive datasets, and model serving runtimes.
Preferred Qualifications
Experience with LLM orchestration frameworks (LangChain, Ray Serve, vLLM).
Bachelor&#x27;s or Master’s degree in Computer Science, Computer Engineering, or a related technical field.
