# [infoq] Azure Logic Apps Standard Gets a Local CLI in Preview

> Source: engineering | Category: engineering | 2026-11-12T12:10:02Z

Azure Logic Apps Standard Gets a Local CLI in Preview

Microsoft has released a public preview of the logicapp extension for the Azure CLI, adding local project creation, workflow authoring, a runtime lifecycle, connector management, run inspection, and test scaffolding for Logic Apps Standard, work that previously required the VS Code extension. The product team pitches the terminal surface as determinism for AI-assisted development.   By Steef-Jan Wiggers
