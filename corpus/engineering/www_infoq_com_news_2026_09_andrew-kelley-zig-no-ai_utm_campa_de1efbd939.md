# [infoq] Andrew Kelley Interview: Why He Built Zig, Banned AI Contributions, and Moved Zig off GitHub

> Source: engineering | Category: engineering | 2026-09-23T12:15:07Z

Andrew Kelley Interview: Why He Built Zig, Banned AI Contributions, and Moved Zig off GitHub

In a JetBrains interview, Zig creator Andrew Kelley expanded on the project’s formal ban on AI contributions and the motivation behind its migration off GitHub to Codeberg: automated code submissions decrease codebase quality and weaken the social constructs between open-source participants; persistent GitHub failures and a perceived misalignment of incentives led to migrating to Codeberg.   By Bruno Couriol
