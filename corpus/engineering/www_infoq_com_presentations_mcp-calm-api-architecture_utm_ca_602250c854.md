# [infoq] Presentation: APIs for Agents: Rethinking API Programs in the MCP Era

> Source: engineering | Category: engineering | 2026-09-23T12:15:07Z

Presentation: APIs for Agents: Rethinking API Programs in the MCP Era

Jim Gough and Andreea Niculcea explain how Morgan Stanley uses Architecture as Code with CALM to modernize its API program. They demonstrate integrating Model Context Protocol (MCP) and Agent-to-Agent (A2A) communications, enforcing automated governance through deployment gates, and executing zero-downtime platform upgrades to safely scale enterprise AI and agentic workflows.   By Jim Gough, Andreea Niculcea
