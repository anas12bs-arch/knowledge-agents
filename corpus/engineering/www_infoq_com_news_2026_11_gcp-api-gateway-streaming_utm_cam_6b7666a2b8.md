# [infoq] Google Cloud API Gateway Introduces Streaming Support for Real-Time and AI-Powered Applications

> Source: engineering | Category: engineering | 2026-11-05T17:44:30Z

Google Cloud API Gateway Introduces Streaming Support for Real-Time and AI-Powered Applications

Google has announced the public preview of streaming support for API Gateway, extending its traditional request-response model to support applications requiring real-time communication. According to Google, this is particularly relevant for AI applications that provide streaming model responses, multi-step agent workflows, and interactive sessions.   By Sergio De Simone
