# [infoq] Vercel Releases UI SDK for Agents to Compose UI from Reusable Behaviors

> Source: engineering | Category: engineering | 2026-11-18T16:26:06Z

Vercel Releases UI SDK for Agents to Compose UI from Reusable Behaviors

Vercel has released UI SDK in beta, an Apache 2.0 TypeScript library of more than 50 UI behaviors in @ui-sdk/core, with adapters for React, Vue, Svelte, Solid, and Web Components, so agents can compose accessible components and operate them through a documented agent bridge.   By Daniel Dominguez
