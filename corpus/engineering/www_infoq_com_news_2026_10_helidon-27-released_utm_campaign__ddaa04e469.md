# [infoq] Helidon 27 Introduces Restructured Programming Models and New Messaging and Data Modules

> Source: engineering | Category: engineering | 2026-10-16T11:40:33Z

Helidon 27 Introduces Restructured Programming Models and New Messaging and Data Modules

The release of Helidon 27 is the first release that follows the Oracle Tip & Tail Model of Library Development by which the Tip adopts the latest Java technology while the Tail provides a more stable and secure baseline. Concurrent with the release of JDK 27, new features in Helidon 27 include: an introduction to new major modules, Helidon Messaging and Helidon Data JDBC.   By Michael Redlich
