# [infoq] AWS Open-Sources Emulator for Local Testing of 200+ Services by Coding Agents

> Source: engineering | Category: engineering | 2026-11-16T17:33:20Z

AWS Open-Sources Emulator for Local Testing of 200+ Services by Coding Agents

AWS Emulator is a generally available local HTTPS endpoint, generated from public Smithy API models, that lets developers and coding agents test against more than 200 AWS services without an account, with published fidelity scores and documented limits around IAM, regions, and in-memory state.
