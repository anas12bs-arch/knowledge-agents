# [infoq] React 19.3: Adds a browser() API, Giving Client-Only Rendering a First-Class Name

> Source: engineering | Category: engineering | 2026-10-12T22:48:19Z

React 19.3: Adds a browser() API, Giving Client-Only Rendering a First-Class Name

React 19.3 was released on September 9, introducing several features including the react-dom browser() API. This API allows components to opt out of server-side rendering, addressing issues with components that rely on client-specific data. It provides a cleaner solution for managing hydration mismatches and supports conditional data fetching, enhancing flexibility for developers.   By Daniel Curtis
