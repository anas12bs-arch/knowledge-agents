# [infoq] Entire's Git Forge Rethinks Git Collaboration for Coding Agents

> Source: engineering | Category: engineering | 2026-11-08T14:36:15Z

Entire's Git Forge Rethinks Git Collaboration for Coding Agents

Entire is a Git forge designed specifically for collaboration between human developers and AI coding agents. Its premise is that traditional software development infrastructure, particularly the pull request (PR) model, is not well suited to an environment where AI agents generate, review, and iterate on code at high speed.   By Sergio De Simone
