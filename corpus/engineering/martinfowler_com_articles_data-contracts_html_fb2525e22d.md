# [martin-fowler] Data Contracts

> Source: engineering | Category: engineering | 2026-11-18T16:26:05Z

Data Contracts

Data contracts are a way to describe the contents and guarantees of
     datasets.  Simon Harrer  and  Arif Wider 
     describe in detail what they are and how to use them. They apply practices
     from API design to data by treating them as data-providing services - such
     as data products - whose interfaces we want to define as clearly as
     possible. This approach significantly increases the robustness of
     large-scale data landscapes, and gives both people and AI agents the
     explicit, trustworthy metadata they need to work with data autonomously,
     which is why more and more enterprises are adopting them.
