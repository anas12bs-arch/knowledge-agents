# [infoq] Google Launches LiteRT Tensor API for Building, Customizing, and Optimizing ML Models for On-Device

> Source: engineering | Category: engineering | 2026-11-04T02:24:32Z

Google Launches LiteRT Tensor API for Building, Customizing, and Optimizing ML Models for On-Device

Google has introduced the LiteRT Tensor API, a lightweight C++ API that allows developers to build, customize, and optimize machine learning models directly for on-device execution. According to Google, it combines the flexibility of native model authoring with cross-platform portability.   By Sergio De Simone
