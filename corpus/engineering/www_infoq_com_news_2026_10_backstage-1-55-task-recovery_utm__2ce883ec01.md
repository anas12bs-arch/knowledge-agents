# [infoq] Backstage 1.55 Adds Scaffolder Task Recovery and Removes Deprecated Catalog APIs

> Source: engineering | Category: engineering | 2026-10-13T22:00:09Z

Backstage 1.55 Adds Scaffolder Task Recovery and Removes Deprecated Catalog APIs

Backstage 1.55 adds opt-in recovery for Software Template tasks, resuming crashed or timed-out runs from the last completed step. The release also carries breaking changes to the catalog, search and TechDocs, so teams should review their configuration before upgrading to the current 1.55.3 patch.   By Mark Silvester
