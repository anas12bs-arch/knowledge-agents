# [infoq] DoorDash Uses Multi Agent LLMs to Clean up 60,000 Feature Flags

> Source: engineering | Category: engineering | 2026-09-18T15:04:07Z

DoorDash Uses Multi Agent LLMs to Clean up 60,000 Feature Flags

DoorDash built a multi-agent LLM system to automate stale feature flag cleanup across more than 60,000 flags and 623 repositories. The workflow combines live experimentation data through MCP, engineer approval, isolated Git worktrees, parallel agents, and automated validation. In an evaluation of 50 flags, 45 produced usable pull requests at an average of 13.8 minutes and $4.79 per cleanup.   By Leela Kumili
