# [infoq] Uber Builds MCP Gateway to Govern Access to 800+ Servers and 5,000+ AI Agent Tools

> Source: engineering | Category: engineering | 2026-11-02T20:02:36Z

Uber Builds MCP Gateway to Govern Access to 800+ Servers and 5,000+ AI Agent Tools

Uber has built an MCP Gateway to standardize how AI agents discover and invoke internal services across more than 800 MCP servers and 5,000 tools. The gateway separates tool registration from runtime execution and includes automated API discovery, access controls, sensitive data redaction, incremental tool discovery through Omni MCP, and response filtering.
