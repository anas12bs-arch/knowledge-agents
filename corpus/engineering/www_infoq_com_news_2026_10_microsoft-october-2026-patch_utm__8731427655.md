# [infoq] Microsoft's October Security Update Fixes 1,400+ Vulnerabilities, One Exploited in the Wild

> Source: engineering | Category: engineering | 2026-10-28T13:50:36Z

Microsoft's October Security Update Fixes 1,400+ Vulnerabilities, One Exploited in the Wild

Microsoft's latest monthly security update addresses 1415 vulnerabilities across multiple products. One vulnerability affecting Windows Shell has been exploited in the wild, while 85 are classified as critical. Affected products include Windows OS, Office, Exchange, .NET, Edge, as well as potentially Hyper-V and Azure components.   By Sergio De Simone
