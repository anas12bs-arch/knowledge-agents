# [infoq] Microsoft Retires Azure Deployment Environments with No Replacement Product

> Source: engineering | Category: engineering | 2026-10-30T17:09:05Z

Microsoft Retires Azure Deployment Environments with No Replacement Product

Azure Deployment Environments retires on February 22, 2027 and Microsoft names no successor, telling teams to use Bicep or ARM templates directly. Microsoft Dev Box follows on September 18, 2028, pointed at Windows 365, which Microsoft says is not a one-to-one replacement. Remaining Dev Box workloads should expect deletion.   By Steef-Jan Wiggers
