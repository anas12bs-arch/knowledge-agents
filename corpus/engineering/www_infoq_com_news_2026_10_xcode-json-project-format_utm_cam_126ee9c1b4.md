# [infoq] Xcode 27.2 Introduces an Agent- and Merge-Friendly JSON Format for Project Configuration

> Source: engineering | Category: engineering | 2026-10-12T22:48:19Z

Xcode 27.2 Introduces an Agent- and Merge-Friendly JSON Format for Project Configuration

Apple is introducing a new JSON-based format for Xcode project configuration files, replacing the traditional property-list-based format. Available in Xcode 27.2, the new format aims to improve readability, simplify maintenance, and make project configuration easier for AI coding agents to understand and modify.   By Sergio De Simone
