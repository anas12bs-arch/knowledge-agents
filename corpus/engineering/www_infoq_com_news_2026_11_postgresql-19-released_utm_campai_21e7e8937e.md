# [infoq] PostgreSQL 19 Released with Online Table Repacking and Query Planning Controls

> Source: engineering | Category: engineering | 2026-11-22T19:18:57Z

PostgreSQL 19 Released with Online Table Repacking and Query Planning Controls

The PostgreSQL Global Development Group released PostgreSQL 19, introducing changes to database maintenance, query planning, replication, and application development. The release focuses on reducing administrative overhead and improving performance, with new tools for reorganizing tables without downtime and controlling query plans.   By Robert Krzaczyński
