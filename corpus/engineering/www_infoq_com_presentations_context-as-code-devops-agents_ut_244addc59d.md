# [infoq] Presentation: Context Is the New Code

> Source: engineering | Category: engineering | 2026-09-30T23:45:36Z

Presentation: Context Is the New Code

Patrick Debois discusses how to manage, evaluate, distribute, and observe context using proven software engineering practices. He shares how treating context like code - complete with testing, CI/CD, package managers, and security scanning - enables engineering leaders to reliably scale AI coding agents, maintain control over non-deterministic outputs, and build long-term organizational knowledge.   By Patrick Debois
