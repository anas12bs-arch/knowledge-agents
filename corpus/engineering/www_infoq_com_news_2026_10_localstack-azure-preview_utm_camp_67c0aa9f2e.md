# [infoq] LocalStack for Azure Enters Public Preview with Security Settings Stored but Not Enforced

> Source: engineering | Category: engineering | 2026-10-31T12:53:00Z

LocalStack for Azure Enters Public Preview with Security Settings Stored but Not Enforced

LocalStack has opened its Azure emulator to a free public preview, running Azure services locally and accepting existing ARM, Bicep, and Terraform without rewrites. Its own documentation reports partial operation coverage per service and a consistent pattern: configuration is stored and returned, while enforcement of access restrictions, TLS, and network rules is not implemented.
