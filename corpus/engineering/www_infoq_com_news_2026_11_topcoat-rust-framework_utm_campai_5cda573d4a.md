# [infoq] Tokio Releases Topcoat: A Batteries-Included Full-Stack Rust Framework

> Source: engineering | Category: engineering | 2026-11-09T09:04:10Z

Tokio Releases Topcoat: A Batteries-Included Full-Stack Rust Framework

Topcoat is an open-source, server-rendered full-stack web framework for Rust from the Tokio team, now public at version 0.9. It uses Rust expressions translated to JavaScript for reactivity instead of WebAssembly. It targets typical database-driven apps. Releases are unstable, and authentication and background jobs remain on the roadmap.   By Daniel Curtis
