# [infoq] Akka Tests Spec-Driven AI Delivery Across 65 Open Source Projects

> Source: engineering | Category: engineering | 2026-10-06T01:33:39Z

Akka Tests Spec-Driven AI Delivery Across 65 Open Source Projects

Akka used 65 open-source projects to examine how specification structure, context, model selection, automated validation, and delivery guardrails affect AI assisted software porting. The experiment measured time, token use, code size, test parity, and performance, finding substantial variation across models, effort levels, and project types.   By Leela Kumili
