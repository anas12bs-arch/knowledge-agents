# [infoq] AWS Introduces Foreign Key Constraints in Aurora DSQL

> Source: engineering | Category: engineering | 2026-09-28T12:03:35Z

AWS Introduces Foreign Key Constraints in Aurora DSQL

AWS recently announced that Aurora DSQL now supports foreign key constraints, allowing applications to enforce referential integrity directly in the database, including CASCADE, SET NULL, and other referential actions. The addition addresses a long-standing gap that users had explicitly called out as an adoption blocker.   By Renato Losio
