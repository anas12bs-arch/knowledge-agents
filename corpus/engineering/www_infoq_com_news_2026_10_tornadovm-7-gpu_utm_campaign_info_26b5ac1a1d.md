# [infoq] TornadoVM 7 Enables GPU-Native Workloads From Java Applications

> Source: engineering | Category: engineering | 2026-10-21T11:42:39Z

TornadoVM 7 Enables GPU-Native Workloads From Java Applications

TornadoVM, an open-source heterogeneous programming framework for Java has reached version 7.0. It automatically accelerates Java programs on multi-core CPUs and GPUs and provides a rich GPU programming ecosystem in Java that can be used with any mainstream JDK distribution e.g. Temurin, Red Hat OpenJDK, Coretto, Oracle, GraalVM or Zulu.
