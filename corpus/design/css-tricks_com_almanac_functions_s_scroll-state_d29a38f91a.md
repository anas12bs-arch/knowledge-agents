# [css-tricks] scroll-state()

> Source: design | Category: design | 2026-11-19T20:54:56Z

scroll-state()

The CSS scroll-state() query, surprisingly, has nothing to do with whether you’re doom-scrolling in a state of existential dread. It does, however, allow you to change the CSS used based on scrolling behavior.
