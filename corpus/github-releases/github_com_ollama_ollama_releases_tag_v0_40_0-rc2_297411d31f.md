# ollama/ollama v0.40.0-rc2 released

> Source: github-releases | Category: changelog | 2026-10-04T18:45:59Z

## ollama/ollama — v0.40.0-rc2

## What's Changed

**Models run on MLX on Apple Silicon by default**

In this release, on Apple Silicon devices, model architectures supported by the MLX runtime will automatically run on MLX.

```
ollama pull qwen3.8
ollama run qwen3.8
```

During the pre-release we will be testing and enabling additional models.
