# langchain-ai/langchain langchain-typesafe==0.1.0 released

> Source: github-releases | Category: changelog | 2026-11-11T17:12:27Z

## langchain-ai/langchain — langchain-typesafe==0.1.0

**`langchain-typesafe` 0.1.0 drops support for Python 3.10**, which has reached end-of-life. The minimum supported version is now Python 3.11, and the minimum `langchain-core` version is now 1.8.0 (`langchain` 1.5.0 for the `experimental` extra). Users on Python 3.10 will continue to resolve `langchain-typesafe` 0.0.x.

Changes since langchain-typesafe==0.0.2

release(typesafe): 0.1.0 (#41800)
refactor(typesafe): deprecate experimental middleware (#41768)
feat(typesafe): implement TypeSafeClassifier as a decision model (#41767)
