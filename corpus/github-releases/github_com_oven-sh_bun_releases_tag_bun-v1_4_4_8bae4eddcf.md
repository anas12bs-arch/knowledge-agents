> Source: github-releases | Category: changelog | 2026-10-22T23:33:06Z

## oven-sh/bun — bun-v1.4.4

To install Bun v1.4.4
```bash
curl -fsSL https://bun.com/install | bash
# or you can use npm
# npm install -g bun
```

Windows:
```bash
powershell -c "irm bun.com/install.ps1|iex"
```

To upgrade to Bun v1.4.4:
```bash
bun upgrade
```
