# [changelog] Warp bets on the software factory (Interview)

> Source: podcast | Category: audio | 2026-11-25T05:45:30Z

Warp bets on the software factory (Interview)

Zach Lloyd, founder and CEO of Warp, is back to talk about what he calls the company's primary bet: Warp Factories, open infrastructure for running a cloud software factory, which he calls the new version of CI/CD. He explains factory as code, what's inside an agent trace, why self-improving systems drift, and how his senior engineers went from guardians of the code to the biggest adopters once the models got good enough. Then he and Adam get into whether this is a pivot, why the best interface might be no new interface at all, coding as a team in Slack, and Adam's case for continuous flow.
