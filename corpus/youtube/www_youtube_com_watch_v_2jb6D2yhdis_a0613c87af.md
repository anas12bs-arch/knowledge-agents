How to evaluate your WebMCP tools

Are your AI agents using your WebMCP tools correctly? Learn how to write evaluations or "evals" to test non-deterministic agent behaviors that traditional unit tests can't catch. Discover how to use the open-source webmcp-evals CLI to evaluate tool selection, review agent trajectories, and debug user journeys across repeated runs.
