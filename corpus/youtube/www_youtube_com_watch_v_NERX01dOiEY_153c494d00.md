> Source: youtube | Category: video | 2026-10-27T22:19:48Z

What is WebMCP?

WebMCP is a JavaScript API that lets your website give agents tools to use on the page for actions such as searching, filling in a form, or making a booking. For a complex use journey, it can be difficult for agents to synthesize screenshots, DOM, and an accessibility tree into an actionable plan. With WebMCP, your page explicitly defines what actions they can take. Check out the docs and try WebMCP today!
