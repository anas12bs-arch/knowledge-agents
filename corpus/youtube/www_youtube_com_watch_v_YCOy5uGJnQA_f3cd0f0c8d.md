# [leerob] How to build safer WebMCP tools for AI agents

> Source: youtube | Category: video | 2026-10-30T17:09:27Z

How to build safer WebMCP tools for AI agents

Are your WebMCP tools secure against unintended actions or prompt injections 

Learn how to build safer tools to protect your web applications and user data. Discover how to add annotations directly to your tool definitions, like consequentialHint for high-stakes operations, readOnlyHint to reduce permission pop-ups, and untrustedContentHint to safeguard against indirect prompt injections by indicate that tool outputs contain untrusted content that requires data spotlighting. 

You can inspect all of these security hints directly inside Chrome DevTools.
