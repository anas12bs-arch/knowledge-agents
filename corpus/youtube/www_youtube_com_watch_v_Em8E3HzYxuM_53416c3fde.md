> Source: youtube | Category: video | 2026-11-20T23:28:49Z

OnnxRuntime Web

As models move from the cloud to user devices, the browser is emerging as a universal AI runtime that spans Windows, macOS, Linux, Android, and iOS. ONNX Runtime Web enables this shift by allowing developers to run state-of-the-art AI models directly in the browser with GPU acceleration, while maintaining the portability and ecosystem benefits of ONNX. In this talk, we'll examine how our stack is helping transform the web into a first-class platform for AI.
