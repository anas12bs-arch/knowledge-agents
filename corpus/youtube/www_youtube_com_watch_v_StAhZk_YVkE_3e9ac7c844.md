# [leerob] Memory debugging with agents

> Source: youtube | Category: video | 2026-11-06T10:01:21Z

Memory debugging with agents

DevTools for agents now provides dedicated memory debugging tools to help identify memory leaks in web applications. By enabling the memory debugging flag in your configuration, your coding agent can capture and compare heap snapshots using the classic three-snapshot method. It systematically inspects retained sizes, which allows it to locate detached DOM nodes and orphaned event listeners holding references in memory. Memory issues can come in all forms, shapes, and sizes and now you can delegate the tedious parts to your coding agent.
