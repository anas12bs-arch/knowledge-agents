> Source: youtube | Category: video | 2026-06-16T23:15:55Z

Stop prompt injection with WebMCP for a safer web.

Sarah introduces WebMCP, a standard that provides websites with the ability to declaratively or imperatively surface tools to agents on the web, providing a bedrock for experiences for those agents. Discover how WebMCP can help protect users and improve the security of the web by helping to mitigate Agent Traps, a type of prompt injection attack, and how Sarah's thinking about improving the security for agents even further.
