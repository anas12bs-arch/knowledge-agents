# [leerob] Distributing an LLM across machines, and coding with it. Entirely in the browser

> Source: youtube | Category: video | 2026-11-24T04:26:43Z

Distributing an LLM across machines, and coding with it. Entirely in the browser

What if your browser could run a coding agent and open-weight LLMs too large for one machine? RallyCompute shards models across tabs on multiple machines via WebGPU, WebAssembly llama.cpp, and WebRTC. Meanwhile, the File System Access API edits code locally. It's distributed inference and agentic coding without leaving the browser!
