RIP Replay XHR, Meet Resend

Learn how to use the new Resend feature in the Chrome DevTools Network panel. Now that Replay XHR is officially retired, this update allows you to instantly refire requests while preserving headers, cookies, and payloads. You can also select the option to edit and resend as a fetch request if you need to tune parameters in the Console beforehand. Keeping your browser up to date ensures you always have access to these helpful network testing enhancements.
