# [hacker-news-sec] Google Chrome Adds ClickFix Warnings to Stop Users From Running Malicious Commands

> Source: security | Category: security | 2026-10-21T16:07:21Z

Google Chrome Adds ClickFix Warnings to Stop Users From Running Malicious Commands

Google on Tuesday said it's rolling out improved safeguards in its Chrome browser to secure users against ClickFix attacks when Enhanced Protection is enabled.

ClickFix is a popular social engineering technique in which bad actors trick users into copying and pasting malicious code directly into their computer's operating system, thereby bypassing conventional security controls.
