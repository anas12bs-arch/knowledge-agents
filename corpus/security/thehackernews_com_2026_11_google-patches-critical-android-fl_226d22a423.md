# [hacker-news-sec] Google Issues Patches for Critical Android Flaw That Could Allow RCE Without User Interaction

> Source: security | Category: security | 2026-11-04T09:31:03Z

Google Issues Patches for Critical Android Flaw That Could Allow RCE Without User Interaction

A critical Android flaw could allow an attacker to run code on a phone without any user action remotely, Google said in its&nbsp;November security bulletin.

The flaw, CVE-2026-58868, affects Android 14 through 17. Phones get the fix with security patch level 2026-11-01 or later, which phone makers and carriers send on their own schedules.
