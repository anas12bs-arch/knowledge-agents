# [schneier] Possible Vulnerability in Apple’s Automatic Reboot

> Source: security | Category: security | 2026-10-06T19:53:11Z

Possible Vulnerability in Apple’s Automatic Reboot

404Media is  reporting  (alternate  link ) that a cyber-weapons arms manufacturer is exploiting a vulnerability in iOS to bypass its automatic reboot security feature. This is the feature that automatically puts an iPhone into a more secure state if it hasn&#8217;t been used for 72 hours. 
  The new technology to get around inactivity reboot was developed by Magnet Forensics, the company behind GrayKey, a popular tool sold to law enforcement agencies that  allows them to unlock and access data stored in iPhones and Android smartphones . Magnet has developed a new device called GrayKey Preserve and a feature for its regular GrayKey devices called Evidence Preservation Mode, according to the video...
