# [hacker-news-sec] Gyazo Breach Exposes 23.62 Million User Records and 490 Million Image Metadata Records

> Source: security | Category: security | 2026-09-17T14:52:59Z

Gyazo Breach Exposes 23.62 Million User Records and 490 Million Image Metadata Records

A security breach at Gyazo, Helpfeel's image-sharing service, exposed about 23.62 million user records, including email addresses and password hashes, the Kyoto-based company said in a&nbsp;notice&nbsp;published Wednesday.

It also exposed about 490 million image metadata records, mostly for images from January 2019 or earlier, including the IDs that make up Gyazo image links.
