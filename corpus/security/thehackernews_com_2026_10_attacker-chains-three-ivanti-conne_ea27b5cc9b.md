# [hacker-news-sec] Attacker Chains Three Ivanti Connect Secure Zero-Days for Root Access, Only Two Patched So Far

> Source: security | Category: security | 2026-10-13T22:00:09Z

Attacker Chains Three Ivanti Connect Secure Zero-Days for Root Access, Only Two Patched So Far

An attacker chained three zero-day flaws in Ivanti Connect Secure, a VPN appliance, to run commands as root without logging in, security firm&nbsp;Volexity said&nbsp;on October 13. Ivanti has released fixes for two of the flaws and told customers on affected versions to "act immediately." A fix for the third is still pending, according to Volexity.
