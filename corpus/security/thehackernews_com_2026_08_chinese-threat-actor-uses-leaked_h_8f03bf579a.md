# [hacker-news-sec] Chinese Threat Actor Uses Leaked DarkSword Kit to Deploy GHOSTBLADE on iOS

> Source: security | Category: security | 2026-08-03T11:21:11Z

Chinese Threat Actor Uses Leaked DarkSword Kit to Deploy GHOSTBLADE on iOS

An unknown Chinese-threat actor has been observed running a campaign targeting Apple iOS devices by leveraging a publicly leaked version of the DarkSword exploit kit.

Attack surface management platform Censys said it identified the threat actor running more than 100 web properties, most of which are fake Amazon Web Services (AWS) sign-in pages on a domain that also hosts the exploit toolkit.
