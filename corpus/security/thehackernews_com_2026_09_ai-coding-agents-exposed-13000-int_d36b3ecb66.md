# [hacker-news-sec] AI Coding Agents Exposed 13,000 Internal Images, Including Billing Records, on GitHub

> Source: security | Category: security | 2026-09-30T23:45:36Z

AI Coding Agents Exposed 13,000 Internal Images, Including Billing Records, on GitHub

AI coding agents asked to share screenshots of code changes for review have put internal company images in public GitHub repositories, security company Glow said.

Its researchers found more than 13,000 internal images from developers at over 300 organizations, including customer billing records and screens of features not yet released. In most cases, they sat under developers' personal accounts
