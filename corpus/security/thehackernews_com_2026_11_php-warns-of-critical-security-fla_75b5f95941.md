# [hacker-news-sec] PHP Warns of Critical Security Flaws Affecting All Supported Versions, Fixes Coming November 19

> Source: security | Category: security | 2026-11-19T12:28:32Z

PHP Warns of Critical Security Flaws Affecting All Supported Versions, Fixes Coming November 19

The maintainers of the PHP programming language on Wednesday issued an advisory announcing an upcoming security release that addresses critical flaws.

The release is scheduled for November 19, 2026, between 2 and 2:30 p.m. UTC.

"These releases are part of PHP's regular four-week release cycle and will address security vulnerabilities affecting all supported PHP versions," the maintainers said.
