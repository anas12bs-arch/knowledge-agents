# [hacker-news-sec] cPGuard Update Channel Hijacked to Backdoor Linux Servers and Collect Password Hashes

> Source: security | Category: security | 2026-11-04T02:24:32Z

cPGuard Update Channel Hijacked to Backdoor Linux Servers and Collect Password Hashes

An attacker broke into the update system of the cPGuard security tool on November 2 and used it to send a malicious script to customers' Linux servers.

The script installed a backdoor and collected password hashes and other sensitive files from servers that ran it, cPGuard maker OPSSHIELD said in an advisory. The attacker has since taken some of that data.

cPGuard 5.88.25 and later versions
