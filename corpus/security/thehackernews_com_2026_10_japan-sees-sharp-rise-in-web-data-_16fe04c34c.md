# [hacker-news-sec] Japan Sees Sharp Rise in Web Data Leaks Amid Mobile API Abuse and Metabase Attacks

> Source: security | Category: security | 2026-10-09T00:18:27Z

Japan Sees Sharp Rise in Web Data Leaks Amid Mobile API Abuse and Metabase Attacks

Attackers behind a string of personal data leaks at Japanese organizations have abused APIs for mobile apps and targeted known software flaws, the JPCERT Coordination Center (JPCERT/CC) said.

The Tokyo-based center, which takes incident reports, based its&nbsp;October 8, 2026 alert&nbsp;on those reports and other information. The alert names no attacker and no affected organization.
