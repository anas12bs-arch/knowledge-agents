# [hacker-news-sec] Drupal Patches Critical Field UI Flaw With Unauthenticated RCE Path via Contributed Modules

> Source: security | Category: security | 2026-10-15T21:37:02Z

Drupal Patches Critical Field UI Flaw With Unauthenticated RCE Path via Contributed Modules

Drupal core has a critical flaw in its Field UI module that could let an attacker run code on the site's server, and fixes were shipped on October 14 in Drupal 11.4.10, 11.3.19, and 10.6.19.

An attacker cannot reach the flaw through core alone, the Drupal Security Team said in&nbsp;its advisory. Several exploit paths exist through contributed modules, and at least one known path needs no login.
