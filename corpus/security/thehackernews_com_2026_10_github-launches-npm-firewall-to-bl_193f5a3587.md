# [hacker-news-sec] GitHub Launches npm Firewall to Block Malicious Packages Before Installation

> Source: security | Category: security | 2026-10-29T15:34:48Z

GitHub Launches npm Firewall to Block Malicious Packages Before Installation

GitHub has announced that it's introducing a new package firewall as a preview to block installation of suspicious npm packages during installation time.

"The firewall inspects both metadata requests and package downloads for signs of malicious activity, acting as an install-time policy gate," GitHub said.

The feature, which currently supports only npm packages, is available in public preview
