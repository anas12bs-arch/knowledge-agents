# [hacker-news-sec] Google Warns LLMjacking Attacks Are Costing Some Enterprises Up to $1 Million in Cloud Charges

> Source: security | Category: security | 2026-11-04T02:24:32Z

Google Warns LLMjacking Attacks Are Costing Some Enterprises Up to $1 Million in Cloud Charges

Google on Monday warned that threat actors are hijacking enterprise access to Large Language Models (LLMs) to fraudulently leverage expensive computing resources and AI services.

The tactic is called LLMjacking, a form of resource hijacking adapted for the LLM era, where an attacker obtains an API key through phishing, source code leaks, misconfigured environments, or exposed client-side code
