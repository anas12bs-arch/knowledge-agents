# How Sentience ships 60+ AI tools in one local desktop app — without locking you into one provider

> Source: devto | Category: news | 2026-06-17T20:37:21Z

Sentience is a PySide6 desktop AI assistant that exposes file ops, browser automation, email, voice, OAuth, and a skills system through OpenAI-style function calling. The interesting part isn't the tools — it's the 4-provider abstraction that lets the same 60+ tool schemas run on Groq, OpenAI, Anthropic, or local Ollama with zero code changes.
