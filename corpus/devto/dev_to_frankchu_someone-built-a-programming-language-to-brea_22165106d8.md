# Someone built a programming language to break LLMs. I ran it.

> Source: devto | Category: news | 2026-10-19T19:29:34Z

KillSwitch is an esolang designed to be unusable by LLMs: a lying spec, anagram-only function calls, values chosen by dice roll. I built its interpreter, ran every sample program, diffed its two specs (484 lines vs 887,584 words of decoy), and found its CLI test suite fails 10/10 on a fresh clone for a naming bug.
