# How Do You Test AI Features That Give a Different Answer Every Time?

> Source: devto | Category: news | 2026-10-04T18:45:22Z

Asserting that an LLM returns an exact string is a guaranteed flaky test. Testing non-deterministic features means checking properties, not strings—and building eval sets, not just unit tests.
