# TypeScript Can't Tell userId From orderId. Branded Types Can.

> Source: devto | Category: news | 2026-11-27T19:30:25Z

TypeScript's structural typing treats userId and orderId as the same type if both are `string` — branded types make them incompatible at compile time.
