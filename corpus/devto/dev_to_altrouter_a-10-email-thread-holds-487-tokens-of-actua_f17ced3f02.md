# A 10-email thread holds 487 tokens of actual text. With quoted replies the model reads 5,068.

> Source: devto | Category: news | 2026-11-22T12:04:50Z

Mail clients quote the whole previous message in every reply, so a thread stored message by message repeats itself. In a 10-message thread the model reads 10.4x the text that was actually written, and a summarizer pays 3.7x for it. One regular expression strips the repeats.
