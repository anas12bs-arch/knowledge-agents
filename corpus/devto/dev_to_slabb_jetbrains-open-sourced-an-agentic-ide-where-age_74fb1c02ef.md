# JetBrains open-sourced an agentic IDE where agents never touch your checkout

> Source: devto | Category: news | 2026-10-26T18:54:28Z

JetBrains open-sourced Thinkrail, an Apache-2.0 agentic IDE where every agent works in its own git worktree, the project's truth lives in a graph of SPEC.md files the agent maintains itself, and there are no accounts. Repo walkthrough: the three ideas worth stealing.
