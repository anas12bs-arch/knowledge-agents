# Same Bytes, 20% Fewer Tokens: Token Counts Are Model-Scoped

> Source: devto | Category: news | 2026-08-22T15:38:08Z

Two sub-agent requests differed by 0.3% in bytes but were billed 20.1% fewer input tokens on the smaller model, which means a token count isn't a property of a request — it's a property of the (request, model) pair.
