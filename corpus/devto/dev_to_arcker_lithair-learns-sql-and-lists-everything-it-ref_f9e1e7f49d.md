# Lithair learns SQL — and lists everything it refuses to promise

> Source: devto | Category: news | 2026-09-20T09:47:20Z

Lithair is a memory-first Rust web framework I build. It just gained a second, SQL storage through a separate crate, lithair-turso: one annotation on the model, same routes. What matters isn't what the adapter can do, it's the list of things it rejects at compile time instead of pretending — and the five releases in two days that followed, one of which fixes a serious bug in the native storage, reported by a real application.
