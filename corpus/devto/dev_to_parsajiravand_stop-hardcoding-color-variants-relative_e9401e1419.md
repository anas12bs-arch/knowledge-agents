# Stop Hardcoding Color Variants. Relative Color Syntax Does It.

> Source: devto | Category: news | 2026-11-01T20:33:39Z

A design system ships one brand color and four hand-picked hex variants for hover, pressed, border, and tint. Change the brand color and four of those five silently go stale. CSS relative color syntax derives every variant from the one color you actually update.
