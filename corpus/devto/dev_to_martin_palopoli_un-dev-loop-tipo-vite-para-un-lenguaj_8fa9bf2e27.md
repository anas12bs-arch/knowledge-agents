# Un dev loop tipo Vite para un lenguaje compilado: hot reload + preservación de state + manifest en vivo

> Source: devto | Category: news | 2026-08-07T00:28:20Z

Fitz compila componentes `.fitzv` a WebAssembly — y `fitz dev` les da el loop de edición que esperás de Vite, no de un compilador: rebuild incremental, auto-refresh del browser, state vivo que sobrevive el reload, y un `fitz.toml` que se re-resuelve sin reiniciar. Cero npm, cero framework externo.
