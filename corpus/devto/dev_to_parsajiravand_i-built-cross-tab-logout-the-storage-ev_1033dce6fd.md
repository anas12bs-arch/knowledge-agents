# I Built Cross-Tab Logout. The storage Event Skipped One Tab.

> Source: devto | Category: news | 2026-10-06T08:00:52Z

A cross-tab 'log out everywhere' feature built on the storage event worked in every tab except the one the user actually clicked in. The storage event never fires in the tab that made the change — and that's spec, not a bug.
