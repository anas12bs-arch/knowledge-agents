# A 133 KB image pasted into my prompt as text cost 122,584 tokens

> Source: devto | Category: news | 2026-11-21T23:58:47Z

When a file reaches an LLM as base64 text, inside HTML, JSON or a tool result, it's billed at about 920 tokens per kilobyte, almost four times the rate of English prose. A 40 KB inline logo turns a 400-token email into a 37,659-token one.
