# DietPi released a new version v10.9

> Source: hackernews | Category: news | 2026-11-27T01:52:25Z

Score: 14 | Comments: 1

DietPi is a lightweight Debian based Linux distribution for SBCs and server systems, with the option to install desktop environments, too. It ships as minimal image but allows to install complete and ready-to-use software stacks with a set of console based shell dialogs and scripts.<p>The source code is hosted on GitHub: https:&#x2F;&#x2F;github.com&#x2F;MichaIng&#x2F;DietPi
The main website can be found at: https:&#x2F;&#x2F;dietpi.com&#x2F;
Wikipedia: https:&#x2F;&#x2F;de.wikipedia.org&#x2F;wiki&#x2F;DietPi<p>The project released the version DietPi v10.9 on November 21st, 2026.<p>The highlights of this version are:<p>Odroid C5, Orange Pi 6&#x2F;6 Plus, Orange Pi Zero 4, Orange Pi 4A: New supported SBCs
Paperless-ngx: New software package: Document management system
Yuvomi: New software package: Self-hosted family planner
SolidPing: New software package: Uptime monitoring tool
Podman: New software package: Daemonless container engine (Docker compatible)
Readarr, Mono: Removed software packages (outdated)
DietPi-Fan_control: New tool, configure temperature-controlled cooling fans on Raspberry Pi
Enhancements for Quartz64, Odroid C2, dietpi-banner, dietpi-cloudshell, dietpi-vpn, dietpi-network, dietpi-software, Node.js, Node-RED
Fixes for UTM-VMs, dietpi-banner, dietpi-vpn, dietpi-network, dietpi-wireguard, dietpi-software
The full release notes can be found at: https:&#x2F;&#x2F;dietpi.com&#x2F;docs&#x2F;releases&#x2F;v10_9&#x2F;
