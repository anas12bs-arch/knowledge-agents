# Show HN: Zpup – Zdog style 3D scenes in JSON, SVG from any angle

> Source: hackernews | Category: news | 2026-11-19T12:28:40Z

Score: 8 | Comments: 0

Hi. I made small project called Zpup. It takes small 3D scene written in JSON and gives back a flat SVG from any angle. There is no JavaScript in the file, so it works in img-tag or README.<p>I needed 3D for small project at my company, and Zdog make big impression on me. But Zdog has not had a release for several years, so I wanted to make modern version.<p>One thing works different. Zdog sorts each shape by one point. so small thing on big floor gets covered when you turn it. Zpup compares the shapes that overlap. You can see both in the README.<p>I wrote it with Claude Code Fable 5.2.<p>No canvas renderer, no text shape, and it is 0.2 version.<p>Playground: <a href="https:&#x2F;&#x2F;rxolve.github.io&#x2F;zpup" rel="nofollow">https:&#x2F;&#x2F;rxolve.github.io&#x2F;zpup</a><p>Feedback is always welcome :)
