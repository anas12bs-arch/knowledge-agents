# Show HN: A Pipeline for Making 10-minute AI Movies with Claude Code and Seedance

> Source: hackernews | Category: news | 2026-07-20T16:07:51Z

Score: 4 | Comments: 1

I&#x27;ve been working on this Claude Code pipeline for making 10-minute movies, gluing together Seedance (videogen), Nano Banana (image gen), and ElevenLabs (voice gen), and using Claude as the director. My repo contributes a markdown playbook and a worked example which should make it easier for other people to make their own short movies. A first-pass movie takes around 2.5 hours of wall clock time and costs around $200, and iterating is easy thanks to intermediate artifacts like storyboards and voice samples.
