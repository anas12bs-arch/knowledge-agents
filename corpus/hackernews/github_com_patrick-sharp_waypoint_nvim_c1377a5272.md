# Show HN: Waypoint.nvim – A Neovim plugin for bookmarking lines of code

> Source: hackernews | Category: news | 2026-07-04T23:30:37Z

Score: 8 | Comments: 0

I made this plugin because I felt like existing bookmark plugins were lacking some important features, including:<p>- The ability to reorder your bookmarks<p>- The ability to delete and move your bookmarks in bulk<p>- The ability to view lines of code around your bookmarks<p>- Syntax highlighting in the preview window<p>- Resilience to the content of files changing (e.g. checking out a git commit that changes the file contents won&#x27;t delete your bookmarks)<p>Let me know what you think!
