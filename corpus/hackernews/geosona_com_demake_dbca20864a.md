# Show HN: demake – one source project compiles to any retro game console ROM

> Source: hackernews | Category: news | 2026-08-06T15:26:41Z

Score: 29 | Comments: 8

This started life as a graphics tool for a specific problem: gen AI can make retro-styled sprites but can&#x27;t follow exact hardware constraints of pixels and colors.<p>While building this I liked the idea that I can fan-out to any retro videogame console or handheld&#x27;s specifications.<p>I then devised my own declarative language - Demotic - to express the game you want to build as concisely and naturally as possible without implementation detail. To work on different machines, you use relative units, like vw, vh, vmin, vmax.<p>It has a web UI, CLI and NPM package. Still a work in progress.
