# Show HN: PaperMono, e-ink fridge magnet shopping list with mobile web page

> Source: hackernews | Category: news | 2026-09-28T19:25:53Z

Score: 99 | Comments: 50

Fridge magnet shopping list on an M5Stack PaperMono (ESP32-S3, e-ink
touchscreen), synced with a phone web app over Wi-Fi. Works offline,
~2,400 lines of C++.<p>This is a great wee device! BLE, Wi-Fi and LoRa on one board makes it flexible
for way more than a shopping list, this is just what I built first. This
firmware only uses Wi-Fi.<p>Fully vibe-coded with Claude Code, I didn&#x27;t hand-write this. I wanted to see
how Claude would get on with building something useful for a new hardware device.<p>As it&#x27;s stuck to the fridge it&#x27;s easy for the family to use, and it&#x27;s already being used day to day which I&#x27;ll admit is a first for a home built project like this
