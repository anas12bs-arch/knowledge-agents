# Show HN: Learning Rust by writing a Markdown to HTML compiler

> Source: hackernews | Category: news | 2026-07-29T01:10:39Z

Score: 3 | Comments: 0

Hi HN,<p>I&#x27;m new to Rust and, after half of `The Rust Programming Language` I decided to delve into a project I would actually use: a markdown to html compiler that actually serves my micro-blog (I started just right after publishing the project hehe). The project is intentionally small and one-file contained: I wanted to have the full picture in mind.<p>I&#x27;m open to comments, suggestions and PRs. If you asked me more convincing arguments to &quot;why did you do it?&quot; rather than &quot;to learn Rust&quot; I would respond with: LLMs are effectively a new type of web users today and will be more and more present in the future. Having a full, well formatted, .md interface of a website can make it easier for them to access the content.
