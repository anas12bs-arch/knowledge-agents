# Show HN: Write GitHub Actions in any language: Loopt

> Source: hackernews | Category: news | 2026-11-09T19:45:25Z

Score: 9 | Comments: 3

Loopt generates the equivalent code for your workflows in any language, then compiles it down to  your workflow files. First-party support for Rust, Python, Typescript, and Go, but it&#x27;s trivial to add a new language. Check it out if you are tired of mangling YAML.
