# [devops-com] AWS Adds Agentic Workspace to Kiro AI Coding Tool

> Source: devops | Category: infrastructure | 2026-08-05T21:09:33Z

AWS Adds Agentic Workspace to Kiro AI Coding Tool

Amazon Web Services (AWS) this week added an open source workspace for its Kiro artificial intelligence (AI) coding tool that enables application developers to asynchronously assign tasks to an AI agent that is capable of autonomously performing tasks, such as testing code as it is created, in a way that maintains context across multiple sessions.
