# [devops-com] Harness Acquires Augment Code Assets to Expand Reach into AI Coding

> Source: devops | Category: infrastructure | 2026-10-09T00:18:28Z

Harness Acquires Augment Code Assets to Expand Reach into AI Coding

Harness today added an artificial intelligence (AI) coding offering to its portfolio after revealing it acquired select assets from Augment Code. The Harness Cosmos Software Factory is based on Cosmos, a set of AI coding agents, an Auggie command line interface (CLI), a Code Context Engine and other related technologies originally developed by Augment Code.
