# [devops-com] AWS Benchmark Aims to Reduce Number of False Positives Found by AI Vulnerability Scanners

> Source: devops | Category: infrastructure | 2026-09-30T23:45:37Z

AWS Benchmark Aims to Reduce Number of False Positives Found by AI Vulnerability Scanners

Amazon Web Services (AWS) has developed a benchmark that can be used to test whether a model can distinguish real vulnerabilities from code that looks risky but is actually safe. The Deception Benchmark was created following an evaluation of the capabilities of 12 models from five different providers. In all, the benchmark includes 14,822 samples [&#8230;]
